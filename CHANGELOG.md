# Changelog

## 0.5.0 - 2026-10-17

- Added employee-number access sessions, login IP recording, admin password unlock, employee role management, and contract activity audit records.
- Added Japanese real-estate and foreign-exchange legal materials to the shared RAG knowledge base.
- Added shared RAG retrieval, on-page evidence display, and persisted retrieval sources for contract generation.

## 0.4.0 - 2026-10-17

- Added Chinese-only, Japanese-only, and default bilingual contract generation options.
- Added a reusable goods sale contract template with prefilled goods, payment, delivery, acceptance, warranty, and liability fields.

## 0.3.3 - 2026-10-17

- Restored editable multi-line template fields and added reusable default clause text, including Japanese housing restrictions and the default second party name.

## 0.3.2 - 2026-10-17

- Limited the generation note to the Contract Generation workspace and closed the LLM settings panel when switching workspaces.

## 0.3.1 - 2026-10-17

- Reduced template inputs, added a final supplementary-provisions field, and added the reserved System Settings tab.
- Renamed the currency template and added editable Word contract downloads.

## 0.3.0 - 2026-10-17

- Replaced the fixed generation form with seven reusable contract templates and a single free-drafting field.
- Added template-specific input fields, source/version metadata, Japanese real-estate references, and selectable recruitment or dispatch modes for Japan IT staffing workflows.

## 0.2.0 - 2026-10-17

- Added a structured contract-generation workspace with drafting inputs, bilingual drafts, assumptions, missing-information checks, and clause coverage.
- Added persistent generation history, Markdown/JSON downloads, and explicit draft-to-review handoff.

## 0.1.4 - 2026-10-17

- Simplified review labels and removed repeated uncertain status labels from the UI.

## 0.1.3 - 2026-10-17

- Enforced actual RAG search limits for standard and deep review modes.

## 0.1.2 - 2026-10-17

- Added standard and deep contract review modes.

## 0.1.1 - 2026-10-17

- Added review stance selection.
